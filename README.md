Titanic Data Analysis

Simple data analysis and charts on the Titanic dataset using Python (pandas and matplotlib).

About the Dataset
titanic.csv is not my work. I only added it here for learning and practice. The original dataset belongs to its real creators.

Charts
- Survival by ticket class (Pclass)
- Survival by gender
- Age comparison (<18 and >=18)

## Main Findings
- Most passengers did not survive.
- Women survived more than men.
- Higher ticket class (Pclass) had better survival rates.
- Age (<18 vs >=18) shows differences in survival and age groups.
